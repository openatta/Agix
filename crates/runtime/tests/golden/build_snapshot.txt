## refused: unparseable session_id
session_id "not-a-session-id" is not a valid SessionId (base58 decode: provided string contained invalid character '-' at byte 3); a history_store requires a parseable id — use `SessionId::new().to_string()` or omit `Builder::session_id`
## refused: scene tool name taken
scene "refused" contributes a tool named "Taken", which is already registered; rename the scene's tool
## refused: plugin tool name taken
a plugin contributes a tool named "Taken", which is already registered by something else
## refused: module order
